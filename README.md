# qbank — ESMO Certificate Question Bank

Personal atomic question bank for the ESMO Certificate of Medical Oncology (CMO) exam preparation.

**Live dashboard:** https://ppacas.github.io/qbank/

Single self-contained HTML file with embedded atomic Q&A + clinical vignette cards across all CMO exam domains, built from ESMO Clinical Practice Guidelines plus published practice-changing evidence. SM-2 spaced repetition with per-module progress tracking, global daily streak, and cross-bank search — all persisted via browser localStorage.

## Coverage

63 modules · ~7,860 atomic cards across 14 exam domains:

Breast · CNS · CUP · Endocrine · Fundamentals · Gastrointestinal · Genitourinary · Gynaecology · Haematology · Head & Neck · Sarcoma & GIST · Skin · Supportive Care · Thoracic

## Notes

- All card content paraphrases published guidelines and trial data; no copyrighted text is reproduced verbatim.
- Card sources cited per card on the back face.
- Built collaboratively with Claude over many sessions.
